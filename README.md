# shortlink

REST API для сокращения ссылок на Go, с аналитикой переходов. Проект
реализуется пошагово, коммит за коммитом, чтобы продемонстрировать
паттерны конкурентности, чистую архитектуру и разработку через тесты.

## Статус

🚧 В разработке — собирается пошагово, коммит за коммитом.

## Стек

- Go (`net/http`, роутер из стандартной библиотеки)
- PostgreSQL
- In-memory кэш для «горячих» ссылок
- JWT-аутентификация
- Docker

## Запуск локально

```bash
go run ./cmd/api
```

Health-check: `GET /api/health`

## Запуск через Docker

```bash
docker compose up --build
```

Поднимает сервис вместе с PostgreSQL. Приложение слушает `:8080` на хосте,
миграции применяются автоматически при старте.

### Переменные окружения

| Переменная                  | Обязательна | По умолчанию | Назначение                                         |
| ---------------------------- | ------------ | ------------ | --------------------------------------------------- |
| `DATABASE_URL`                | да           | —            | DSN подключения к PostgreSQL                        |
| `JWT_SECRET`                  | да           | —            | секрет для подписи JWT                               |
| `PORT`                        | нет          | `8080`       | порт, на котором слушает HTTP-сервер                 |
| `APPLY_MIGRATIONS_ON_START`   | нет          | `true`       | применять ли миграции автоматически при старте       |
